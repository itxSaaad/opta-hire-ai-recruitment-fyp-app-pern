# OptaHire client

React single-page application for candidate, recruiter, interviewer, and admin workflows. It uses same-origin `/api/v1` requests and Socket.IO for chat and interview signaling.

- [Architecture and user journeys](../docs/architecture/README.md)
- [Feature workflows](../docs/features/README.md)
- [API and realtime routes](../docs/api/README.md)
- [Local development](../docs/development/local-setup.md)
- [Environment variables](../docs/development/configuration.md)

Run `npm install` and `npm run dev` from this folder. Only public browser values belong in `VITE_*` variables.
